# PopTheLogo

> Turn your idea into a logo in seconds. Free, fast, and no sign up required.

PopTheLogo is a micro SaaS AI logo maker. Users type an idea, pick a style and aspect ratio, and get a professional logo instantly. Logos are generated on demand and never stored on the server, so the service is private and cheap to run. It is 100% free.

Built with **Next.js 16 (App Router)**, **TypeScript**, **Tailwind CSS v4**, **Supabase** (PostgreSQL + Storage), and **Pollinations.ai** for image generation.

---

## Features

- **Text-to-Logo generator** with 6 styles (Flat, 3D, Minimalis, Vintage, Modern, Abstract) and 3 aspect ratios (Square, Portrait, Landscape).
- **Live loading experience** with animated skeleton and progress indicator.
- **Download PNG**, make again (new seed), and copy prompt.
- **Session history** saved in the browser (cleared when the tab closes).
- **Blog CMS** for SEO articles (Markdown + live preview).
- **Static pages** (About, Privacy, Terms) managed from the admin.
- **Admin dashboard** with lightweight password auth (env-based, signed JWT cookie).
- **SEO**: per-page metadata, Open Graph, JSON-LD, `sitemap.xml`, `robots.txt`, web manifest.
- **Security**: rate limiting (5 req/min/IP), CSP + security headers, httpOnly auth cookie.

## Quick start

```bash
# 1. Install dependencies
npm install

# 2. Configure environment variables
cp .env.example .env.local
#   then edit .env.local (see below)

# 3. Run the dev server
npm run dev
```

Open http://localhost:3000.

> The logo generator works immediately, with **no setup required**. The blog and
> static pages show seed content until you connect Supabase. The admin can only
> read/write real data once Supabase is configured.

### Environment variables

| Variable | Purpose |
|----------|---------|
| `NEXT_PUBLIC_SUPABASE_URL` | Supabase project URL. |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | Supabase anon (public) key. |
| `SUPABASE_SERVICE_ROLE_KEY` | Service role key. **Server only.** Enables admin writes. |
| `ADMIN_PASSWORD` | Password to sign in to `/admin`. |
| `AUTH_SECRET` | Long random string used to sign the admin session JWT. Generate with `openssl rand -base64 32`. |
| `NEXT_PUBLIC_SITE_URL` | Public site URL (canonical, sitemap, OG). Defaults to `http://localhost:3000`. |

### Connect Supabase (for blog + admin)

1. Create a project at https://app.supabase.com.
2. Open the **SQL Editor** and run [`supabase/migrations/0001_init.sql`](supabase/migrations/0001_init.sql). This creates the `blog_posts`, `pages`, and `site_settings` tables, the `media` storage bucket, RLS policies, and seed content.
3. Copy the project URL and keys from **Project Settings → API** into `.env.local`.
4. Restart `npm run dev`. The admin dashboard now reads and writes from Supabase.

## Admin access

- Visit `/admin/login` and enter your `ADMIN_PASSWORD`.
- Manage blog posts, pages, and site settings from the dashboard.

## Tech stack

- **Next.js 16** App Router (Server Components + Route Handlers)
- **TypeScript**
- **Tailwind CSS v4** with a hand-rolled shadcn-style UI kit (Radix primitives)
- **Supabase** (PostgreSQL, Storage)
- **Pollinations.ai** for AI image generation (no API key needed)
- **jose** for JWT session signing
- **react-markdown** for blog content

## Project structure

```
src/
  app/                  routes (public, blog, admin, api, SEO files)
  components/           UI kit + feature components
  lib/                  supabase clients, auth, repositories, helpers
  types/                shared domain + database types
  middleware.ts         protects /admin and /api/admin/*
supabase/migrations/    SQL schema + seed
```

## Deployment (Vercel)

1. Push to GitHub.
2. Import the repo on Vercel.
3. Add the environment variables (same as `.env.local`).
4. Run the Supabase migration (once) if you have not already.
5. Deploy. Set `NEXT_PUBLIC_SITE_URL` to your domain.

## Notes

- Logos are generated by Pollinations.ai on demand and are **not** stored. The
  download route proxies the image bytes with an attachment header.
- Rate limiting is in-memory (single instance). For multi-instance limits, swap
  `src/lib/rate-limit.ts` for Upstash Redis.
- All homepage and marketing copy uses simple English without em dashes.
